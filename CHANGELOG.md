# Changelog

## 0.1.1

- Added an extension icon.
- Repository is now public; added homepage and issues links.

## 0.1.0

- Initial release: custom editor for `.mp4` / `.m4a` / `.aac` / `.mov` audio.
- Transcodes via local `ffmpeg` to WAV (default) or Ogg/Opus, cached in global storage.
- `Audio Preview: Clear Transcode Cache` command.
